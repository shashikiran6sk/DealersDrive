# Derivatives

Generate real320/640/1024/1600 WebP buffers before writing any object. Sharp is
limited to40million input pixels, one native decoding task at a time, bounded
cache, auto-orientation and quality78. Hash original content into immutable keys;
presigned-original reuse cannot overwrite old derivatives. The serialized
promise chain recovers after decoder/storage failure. Public visibility is
checked separately; object immutability does not justify immutable public caches.
