# Agent UAT

Audited commit `6e39a9a6af7a6aaa2806e9eaab9481634fb496d2`, production web build against the
certification API. Driven in Chromium 141 the way a person drives it — taps and clicks, typing,
scrolling, Escape, refresh, Back/Forward, a second tab, double taps, invalid input, leaving a
form half-filled — at phone (390×844, touch, DPR 3), tablet (820×1180) and desktop (1440×900)
sizes. Every step was screenshotted (`EVIDENCE/screenshots/UAT-*`, `GOLDEN-*`, `MEDIA-01*`,
`RECOVERY-00*`) and the screenshots were reviewed by eye; what they show is written below.

**Result: PASS — every journey completed; no step was blocked or misleading enough to stop a
user. Findings: BUG-101 (P2, HTTP status only), BUG-105, BUG-107, BUG-109, BUG-110 (P3).**
