# Acceptance baseline — PR #304 and later

Audited commit `6e39a9a6af7a6aaa2806e9eaab9481634fb496d2` · local isolated container · generated by `harness/write-reports.mjs` from `registry/results.final.json`. Evidence for each row is under `EVIDENCE/<area>/` (area = the harness script's recorder name; see `TEST-TRACEABILITY.csv`).

**Inventory: 556 canonical + 80 discovered = 636 scenarios.**

The brief points to a "Production Acceptance Baseline v2.0" of 676 scenarios. It was searched for on `main` and on all 32 branches of `origin`, by file name and by content (`676`, `v2.0`, `Baseline v2`), and **does not exist** in this repository. Rather than invent 120 scenarios to reach a number, this baseline is the verbatim 556-scenario registry (`registry/canonical-scenarios.txt`, validated by `registry/registry.mjs`) plus every scenario discovered by auditing the 71 commits merged after the last certified commit (`8436820`, #251) up to and including PR #304 and the current head (`6e39a9a`, #330). If a v2.0 file exists elsewhere, its additional IDs can be merged into `registry/` and the campaign re-run; no canonical ID would change.
